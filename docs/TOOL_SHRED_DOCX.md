# Tool: .docx Text Extraction (Dynamic TOC and Hyperlinks)

Code for text extraction used by the shredder. Covers cases that `python-docx` misses:
- Dynamic table of contents generated by Word (TOC fields wrapped in `<w:sdt>`)
- Text carried by hyperlinks (`<w:hyperlink>`) — particularly TOC entries pointing to clause anchors

For bug context, diagnosis, and root cause: see `BUG_HYPERLIENS_TOC_SYNTHESE.md`.

## Location in Production Code

`src/contract_risk_agent.py`, around line 1243. WordprocessingML constants declared above the function. Called from `extract_contract_source` for all `.docx` extensions.

## Signature


Input: path to a `.docx` file. Output: string containing document text, paragraphs prefixed by `[PARAGRAPH N]`, table cells prefixed by `[TABLE I ROW J]`. This markup is used downstream by the shredder to reconstruct structure.

## Complete Code

```python
from pathlib import Path

# WordprocessingML: official namespace for .docx content.
_WORDML_NS = "http://schemas.openxmlformats.org/wordprocessingml/2006/main"
_WORDML_P_TAG = f"{{{_WORDML_NS}}}p"
_WORDML_TBL_TAG = f"{{{_WORDML_NS}}}tbl"
_WORDML_TR_TAG = f"{{{_WORDML_NS}}}tr"
_WORDML_TC_TAG = f"{{{_WORDML_NS}}}tc"


def _xml_paragraph_text_full(p_elem) -> str:
    """
    Full text of a <w:p>: collects all <w:t>, <w:tab/>, <w:br/>
    by visiting all descendants, including hyperlink text
    (used in dynamic TOC fields).
    """
    pieces: list[str] = []
    for elem in p_elem.iter():
        tag = elem.tag.split('}', 1)[-1] if '}' in elem.tag else elem.tag
        if tag == 't' and elem.text:
            pieces.append(elem.text)
        elif tag == 'tab':
            pieces.append('\t')
        elif tag == 'br':
            pieces.append('\n')
    return ''.join(pieces).strip()


def extraire_texte_docx(file_path: Path) -> str:
    """
    Docx extraction that traverses raw XML body, in order, and descends
    into <w:sdt> containers (Structured Document Tags) that python-docx
    ignores by default. This allows recovery of dynamic TOC field text.
    """
    require_module("docx", "python-docx")
    import zipfile
    from xml.etree import ElementTree as ET

    with zipfile.ZipFile(str(file_path)) as archive:
        with archive.open('word/document.xml') as fd:
            tree = ET.parse(fd)

    root = tree.getroot()
    body = root.find(f"{{{_WORDML_NS}}}body")
    if body is None:
        return ""

    parts: list[str] = []
    paragraph_counter = 0
    table_counter = 0

    # Traverse body recursively, in document order.
    def visit(node, table_ctx: dict | None = None) -> None:
        nonlocal paragraph_counter, table_counter
        for child in node:
            tag = child.tag.split('}', 1)[-1] if '}' in child.tag else child.tag

            if tag == 'p':
                if table_ctx is None:
                    paragraph_counter += 1
                    text = _xml_paragraph_text_full(child)
                    if text:
                        parts.append(f"[PARAGRAPH {paragraph_counter}] {text}")
                else:
                    # Paragraph inside table cell
                    text = _xml_paragraph_text_full(child)
                    if text:
                        table_ctx["cell_pieces"].append(text)

            elif tag == 'tbl' and table_ctx is None:
                table_counter += 1
                local_table_idx = table_counter
                row_idx = 0
                for row in child.findall(_WORDML_TR_TAG):
                    row_idx += 1
                    values: list[str] = []
                    for cell in row.findall(_WORDML_TC_TAG):
                        ctx = {"cell_pieces": []}
                        # Recursive visit of cell (includes sdt and p)
                        visit(cell, table_ctx=ctx)
                        joined = ' '.join(ctx["cell_pieces"]).strip()
                        if joined:
                            values.append(joined)
                    if values:
                        parts.append(
                            f"[TABLE {local_table_idx} ROW {row_idx}] " + " | ".join(values)
                        )

            elif tag == 'sdt':
                # Structured Document Tag (used for dynamic TOC):
                # descend into content to not miss anything.
                sdt_content = child.find(f"{{{_WORDML_NS}}}sdtContent")
                if sdt_content is not None:
                    visit(sdt_content, table_ctx=table_ctx)
                else:
                    visit(child, table_ctx=table_ctx)

            else:
                # Other containers (sectPr, etc.): descend just in case.
                if len(child) > 0:
                    visit(child, table_ctx=table_ctx)

    visit(body)
    return "\n".join(parts)
```

## Usage for Redeployment Elsewhere

1. Import `pathlib.Path`, `zipfile`, `xml.etree.ElementTree`.
2. If extracting this code into a standalone module (outside `contract_risk_agent`), replace the `require_module("docx", "python-docx")` call with simple validation or remove if you accept import errors.
3. To also process headers (`word/header*.xml`) and footers (`word/footer*.xml`), visit those files in addition to the archive zip. Not implemented here because analyzed contracts had no structural content in headers/footers.

## Typical Output on .docx with Dynamic TOC

```
[PARAGRAPH 1] EPC AGREEMENT
[PARAGRAPH 2] Project Acme - Solar Farm Phase 2
[PARAGRAPH 3] Summary
[PARAGRAPH 4] 1. Definitions ........... 5
[PARAGRAPH 5] 2. Scope of work ......... 7
[PARAGRAPH 6] 3. Payment ............... 9
...
[PARAGRAPH 72] Section 1. Definitions
[PARAGRAPH 73] In this Agreement, the following terms shall have the meanings...
```

Paragraphs 4–71 in this example are dynamic TOC entries. Before the fix, they were completely missing from output.

## Edge Cases Covered

- **No dynamic TOC**: no `<w:sdt>` encountered, parser just visits `<w:p>` / `<w:tbl>` as before. No regression.
- **TOC inside table cell**: traversal descends into cell and finds nested `<w:sdt>`.
- **Hyperlink with plain text**: recovered by `iter()`, no need to handle `<w:hyperlink>` tag explicitly.
- **Tabs in TOC entry** (the `\t` between title and page number): preserved.
- **`<w:br/>` within paragraph**: converted to `\n`.

## Cases Intentionally Not Covered

- Revision comments (`word/comments.xml`)
- Track changes (`<w:ins>`, `<w:del>` — content is still read because we visit all `<w:t>`)
- OOXML equations (`<m:oMath>`) — math text not recovered
- SmartArt and image alt-text

These were not encountered in analyzed EPC contracts. Add if needed.
